📋 Quick Guide — Kaise Use Karein?

1. Left side mein sidebar se koi bhi section choose karein (Destinations, Packages, etc.)

2. + Add New button se naya item add karein

3. ✏ Edit button se existing item edit karein

4. 🗑 Delete button se item remove karein

5. Sab changes automatically save hote hain — bas website refresh karein to changes dikhein

💡 Tip: Images ke liye URL paste karein. Aap free image hosting jaise imgbb.com ya imgur.com use kar sakte hain.

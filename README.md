# Varish Tour & Travels 🌍✈️

A modern, responsive travel agency website showcasing India's top travel destinations including Kashmir, Jaisalmer, Saputara, Mount Abu, and custom tour packages.

## ✨ Features

- **Interactive Tour Destinations**: Browse curated packages with real-time pricing and itineraries.
- **Dynamic Booking & Inquiries**: Easy booking and contact forms for seamless trip reservations.
- **Admin Dashboard**: Included `admin.html` for managing inquiries, bookings, and destination listings.
- **Responsive & Modern Design**: Clean animations, mobile-first responsive layout, and interactive UI.
- **Fast & Lightweight**: Pure HTML5, CSS3, and modern Vanilla JavaScript without bloated frameworks.

## 📁 Project Structure

```
varish-tour-travels/
├── index.html        # Main landing and travel booking page
├── admin.html        # Admin portal for inquiries & management
├── style.css         # Styling and design system
├── script.js         # Interactive behavior and client logic
├── .gitignore        # Git ignore rules
└── *.jpg             # Destination and branding assets
```

## 🚀 Getting Started

Simply open `index.html` in your favorite web browser or serve it using any local web server (e.g., Live Server in VS Code).
